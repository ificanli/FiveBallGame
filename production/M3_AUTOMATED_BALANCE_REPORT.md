# M3 自动规则与平衡烟测报告

状态：`AUTOMATED_BALANCE_PASS / HUMAN_VALIDATION_REQUIRED`

## 范围

- 100 个共享 Seed 的规则级成对反事实。
- 对照：无徽章、纯净组合、撞库连锁、功能墙冒险。

| 纯净组合 | 100 | 180.0 | 150 |

## 证据边界

- 该烟测证明三套 Build 读取不同路线证据、能稳定触发且当前没有非有限/爆炸分数。
- 代理使用规则夹具，不模拟真实瞄准误差、球路可达性、理解成本、结算节奏或情绪。
- 不能据此宣称游戏好玩、三套 Build 已平衡或玩家会主动改变球路。
- 真人仍必须完成隐藏分数录像辨识和实际 15～25 分钟 Run。
