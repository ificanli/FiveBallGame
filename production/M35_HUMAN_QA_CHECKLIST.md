# M3.5 UI 品质提升 — 真人验收清单

版本：`feature/ui-interaction-and-build-polish`
构建：`builds/windows/FiveBallGrandSlam.exe`
验收人：产品负责人

## 启动

双击 `builds/windows/FiveBallGrandSlam.exe`，应进入主菜单（五球满贯 · 开始巡回 / 教程 / 退出）。

## 逐项验收

### 1. 主菜单与场景流
- [ ] 主菜单三个按钮可见、可点击、中文正确
- [ ] 点「开始巡回」进入球桌，先弹出「选择一枚桌边徽章」三选一
- [ ] 点「教程」进入球桌，底部出现新手引导，可关闭
- [ ] 「退出」能关闭游戏

### 2. 奖励三选一
- [ ] 三张卡片显示徽章名称、流派标签、定位、中文说明
- [ ] 鼠标点击卡片可选中；按 1/2/3 也可选中
- [ ] 选中后进入球桌，右侧 HUD 显示已装备徽章（带流派颜色）

### 3. 右侧 HUD 与出杆
- [ ] HUD 显示目标分、当前分、剩余杆数、球组数
- [ ] 5 个球槽正确显示球的颜色、数字、副本/球#标记
- [ ] 最佳组合名称与公式正确
- [ ] 结算/保留/重置/道具/菜单按钮可点击，禁用状态正确
- [ ] 鼠标瞄准、点击出杆、1~5 力度、Tab 辅助线、←/→ 微调均正常

### 4. 杆后决策
- [ ] 出杆停止后，「结算」「保留」按钮可用，点击有中文反馈
- [ ] 爆仓时出现中文提示

### 5. 道具选择器
- [ ] 按 Q 或点「道具」打开选择器，显示持有道具的中文说明
- [ ] 选择「软袋/保险球槽/清台重开」直接生效
- [ ] 选择「调色粉笔」后提示点击本手球，选球后弹出颜色选择（红/蓝/黄/绿）
- [ ] 选择「数字贴纸」后选球，弹出 +1/-1 选择
- [ ] 选择「退球钩」后选球直接生效
- [ ] 取消（Esc）不消耗道具、不改变状态

### 6. 徽章管理
- [ ] 暂停菜单里「徽章管理」打开列表，显示名称、流派、中文说明
- [ ] ↑/↓ 能调整顺序，HUD 同步更新
- [ ] 槽满时选新徽章，弹出「选择被替换的徽章」，点「替换」生效

### 7. 暂停与返回
- [ ] Esc 打开暂停（继续/徽章管理/重开/回主菜单）
- [ ] 「重开」回到同种子新局
- [ ] 「返回主菜单」回到主菜单

### 8. 结算统计
- [ ] 三桌全部达标后显示「巡回胜利」与统计（各桌得分、最终得分、徽章、结算/保留/爆仓/道具次数）
- [ ] 「相同种子重新开始」与「返回主菜单」可用

### 9. 字体与分辨率
- [ ] 1280×720 下无方框字、按钮不截断、说明文字可读（必要时换行）
- [ ] 1920×1080 下同样可读
- [ ] 最长徽章/道具说明不遮挡、不溢出

### 10. 中文完整性
- [ ] 全程无需阅读任何英文即可完成操作
- [ ] 无 `SETTLE` / `KEEP` / `BUST` / `TARGET` / `SCORE` 等英文原型词
