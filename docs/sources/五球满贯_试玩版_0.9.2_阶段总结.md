# 《五球满贯》试玩版 0.9.2 阶段总结

## 一、当前版本定位

本阶段完成了《五球满贯》的首个可对外试玩版本。

核心玩法已经稳定为：

> 发射白色母球，收集被撞到的彩色数字球；利用数字与颜色组成对子、三条、炸弹、顺子、同色、同色顺等组合，在有限杆数内完成目标积分。

玩家可以立即结算当前球组，也可以保留球组继续打一杆，尝试升级组合，但第六颗球会使当前未结算球组爆仓。

## 二、本阶段完成的核心内容

### 1. 基础击球与物理

- 白色母球不带数字、不参与组合。
- 支持五档固定力度，降低连续力度难以复现的问题。
- 拉杆距离与力度档位重新匹配，扩大低档力度操作空间。
- 支持两种操作方式：
  - 拉杆出手；
  - 精细瞄准：方向、力度分开调整。
- 拉杆期间可以用鼠标右键取消。
- 缩小物理碰撞半径，改善球体“隔空碰撞”的观感。
- 辅助线提供简洁、标准、完整三档设置，并保存玩家选择。

### 2. 数字球与组合计分

- 数字球分为未收球、本手球、废球三种状态。
- 已收数字球继续留在桌面参与碰撞，但不能重复收入球槽。
- 结算后，本手实体球会变成废球。
- 支持的主要组合包括：
  - 对子；
  - 三条；
  - 炸弹（四个相同数字）；
  - 五球满贯（五个相同数字）；
  - 顺子；
  - 同色；
  - 同色顺。
- 当前每手只结算最高价值组合，不叠加多个普通组合。
- 未参与最佳组合的污染球默认不提供基础分，但仍占用球槽。

### 3. 功能墙与球路规划

- 复制墙：复制实际撞上墙体的激活数字球至球槽。
- 染色墙：同步改变实体数字球和对应球槽记录的颜色。
- 所有激活球都可以触发功能墙，不再只处理“最近收集球”。
- 增加墙体充能标识：可用与耗尽状态明确显示。
- 辅助线会提示主要碰撞路径、预计触墙球和功能墙归属，但不直接解出完整物理题。
- 中后期加入球童补给墙，可在局内获得容错道具。

### 4. 关卡与长期循环

- 删除生命值、每三杆固定扣血和 Boss 血条模式。
- 改为限定杆数达到目标积分：
  - 资格桌：4 杆；
  - 高额桌：6 杆；
  - 庄家桌：8 杆。
- 一轮包含资格桌、高额桌和庄家桌。
- 满贯巡回包含 8 轮、24 桌。
- 庄家桌使用特殊规则改变球桌条件。
- 每桌结束自动保存，可继续巡回。

### 5. 徽章与道具

- 桌边徽章作为永久 Build 系统，从左到右参与结算。
- 徽章会读取真实击球信息，包括：
  - 力度档位；
  - 撞库；
  - 球球连锁；
  - 复制和染色；
  - 满仓；
  - 污染球。
- 当前已加入 17 枚徽章，但流派结构仍需下一轮统一梳理。
- 徽章和消耗道具分池投放，不再混投。
- 当前奖励节奏：
  - 开局选择徽章；
  - 资格桌后选择道具；
  - 高额桌后选择徽章；
  - 庄家桌后选择道具。
- 已实现的主要道具包括：
  - 清台重开；
  - 软袋；
  - 调色粉笔；
  - 数字贴纸；
  - 退球钩；
  - 重赛券。

### 6. 桌面清理与容错

- 数字球可以通过真实袋口自然落袋。
- 正式球桌提供指定落袋次数，可定向清除废球。
- 指定落袋可在瞄准阶段或一杆结束后使用。
- 废球过多时有自动上限保护，防止桌面完全堵死。
- 巡回开局赠送一次清台重开，其他容错道具随流程获得。

### 7. 教程与局外界面

- 完成独立局外主菜单：
  - 教程关；
  - 满贯巡回；
  - 真人对战（预留）；
  - 玩法与设置。
- 教程改为黑色蒙版、高亮目标区域和说明卡的传统引导方式。
- 点击蒙版只跳过当前提示，不退出教程。
- 教程覆盖：
  - 击球；
  - 收球和得分；
  - 功能墙；
  - 五球槽；
  - 爆仓；
  - 达标通关。
- 教程明确说明：正式球局爆仓只清空当前未结算球组，不会结束整局，也不会扣除已有积分。
- 点击已装备徽章可以查看详细效果。
- 徽章选择期间可以临时查看球桌，再返回原候选列表。

## 三、当前已知问题与风险

### 1. 徽章缺乏明确流派感

当前徽章数量已经足够，但更像独立加分项，尚未形成清晰的启动器、核心件和放大器组合。

下一轮需要统一审核：

- 纯净组合流；
- 污染球／杂球流；
- 撞库技术流；
- 连锁碰撞流；
- 功能墙工程流；
- 满仓冒险流；
- 清台／废球流。

审核文档：

- `E:/NewGame/designs/五球满贯_徽章与道具审核稿.md`

### 2. 难度与倍率曲线仍需真实玩家验证

当前方向是：

- 前期验证基本策略；
- 中期让徽章 Build 成型；
- 后期验证高倍率组合与胡牌能力。

但目标分、徽章倍率、道具频率和补球质量仍需根据外部试玩数据调整。

### 3. 两小时内容目标尚未被完整验证

设计目标为首次完整通关约 90～120 分钟，但目前尚未完成多人长跑验证。需要确认：

- 中后期是否重复；
- 24 桌是否过长；
- 难度是否突然断层；
- Build 是否能在中期形成；
- 后期是否真的出现倍率爆炸。

### 4. 手机适配仍需真机覆盖

目前已完成常见窄屏尺寸的浏览器模拟，但不同品牌手机仍可能存在：

- 系统导航栏和刘海安全区差异；
- WebView 字体缩放差异；
- 触摸拖拽精度差异；
- 极端长宽比下侧栏过窄；
- 部分机型安装或安全扫描提示。

### 5. 真人对战尚未实现

主菜单已预留入口，但还没有对战规则、联网或本地双人模式。

## 四、建议重点收集的试玩反馈

### 核心手感

1. 哪种操作模式更顺手？
2. 五档力度是否容易理解和复现？
3. 辅助线是否足够帮助判断，又没有直接替玩家解题？
4. 碰撞、停止速度、反弹和落袋是否自然？

### 规则理解

1. 玩家是否能理解“最多五球，第六球爆仓”？
2. 玩家是否理解已收球、废球和污染球？
3. 复制墙和染色墙的作用对象是否清楚？
4. 玩家是否知道什么时候应该结算，什么时候继续打一杆？

### 难度与成长

1. 玩家在哪一桌首次失败？
2. 失败原因是操作、规则不懂、目标过高还是随机局面太差？
3. 徽章是否真的改变了打法？
4. 道具是否有用，还是经常忘记使用？
5. Build 从第几轮开始成型？
6. 后期倍率是否足够爽？

### UI 与教程

1. 首次进入是否知道从哪里开始？
2. 教程是否太长、太短或漏掉关键规则？
3. 手机端是否有看不见、点不到或文字太小的区域？
4. 徽章和道具效果是否容易查阅？
5. 目标积分、本桌积分和剩余杆是否始终清楚？

### 内容节奏

1. 玩了多久后想停？
2. 24 桌是否重复或拖沓？
3. 哪类球桌或庄家规则最有趣？
4. 哪些桌面布局令人烦躁而不是有挑战？
5. 玩家是否愿意重新开一局尝试不同 Build？

## 五、下一轮建议迭代顺序

### P0：根据外部反馈修复阻塞问题

- 黑屏、崩溃、存档损坏；
- 无法进入下一桌；
- 按钮或界面不可见；
- 组合识别错误；
- 无法结算、落袋或使用道具；
- 手机端严重触控问题。

### P1：重构徽章和道具流派

- 统一审核所有徽章；
- 每个流派至少包含启动器、核心件和放大器；
- 删除只提供平淡小数值、不会改变打法的徽章；
- 让道具既提供容错，也能服务具体流派；
- 补充清楚的流派提示和徽章关联信息。

### P2：重调目标分与成长曲线

- 使用真实通关率和失败桌数据调整 24 桌目标；
- 保持资格桌 4 杆、高额桌 6 杆、庄家桌 8 杆的节奏；
- 提高成型 Build 的倍率上限；
- 控制前期随机卡死；
- 保证后期仍要求胡出大组合，而不是只靠固定小分过关。

### P3：改善内容变化

- 增加有辨识度但可预判的球桌布局；
- 增加庄家规则；
- 调整功能墙和补给墙的出现节奏；
- 增加球桌外观和阶段表现；
- 让每轮形成更明确的主题。

### P4：继续打磨手机端

- 真机覆盖不同分辨率；
- 进一步压缩窄屏 UI；
- 处理安全区和系统导航栏；
- 优化触控瞄准、取消拉杆与按钮反馈；
- 根据需要提供更清晰的竖屏转横屏提示。

### P5：真人对战设计与实现

建议先确定对战形态，再开发：

- 同设备轮流击球；
- 异步分数对战；
- 实时联网对战；
- 使用同一桌面种子的公平挑战。

首版优先考虑“同种子异步挑战”或“本地轮流”，开发和测试风险低于实时联网。
