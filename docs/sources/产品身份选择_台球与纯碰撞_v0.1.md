# 《五球满贯》产品身份选择：台球与纯碰撞 v0.1

更新时间：2026-08-17
状态：决策完成；方案 B“纯碰撞构筑”胜出，方案 A“落袋满贯”否决

> 当前需要决定的不是美术皮肤，而是玩家应该用什么既有直觉理解游戏。是“我正在打一种奇特台球”，还是“我在操纵一台以圆球碰撞做组合的物理机器”。

---

# 一、共同不变量

无论最终采用哪种身份，都保留：

- 圆形物体；
- 明确颜色和数字；
- 固定步长、可复现的碰撞；
- 拉杆或蓄力发射；
- 连撞与库边反弹；
- 功能墙加工；
- 数字、颜色和数量组合；
- 徽章 Build 改写球路价值；
- 一次操作产生可见连锁；
- 固定 Seed、回放与规则测试。

因此 Godot 技术底座可以共用，不必先决定美术才开始物理验证。

---

# 二、方案 A：风格化台球 Roguelite

## 玩家第一认知

> 这是一款规则奇特、可以构筑的台球游戏。

## 核心语法

- 六个袋口；
- 数字球真正落袋才进入组合；
- 合法进球续杆；
- 母球落袋犯规；
- 走位、安全球和清台；
- 功能墙参与进球前的做球加工；
- 成功后选择锁分交权，或继续连杆冲大组合。

## 优势

1. 台球用户能立即理解基本目标；
2. 准度、走位、连杆、安全球已有成熟技巧深度；
3. PvP 球权切换自然；
4. 观看性和对抗性强；
5. 圆球、球杆、球桌与袋口无需重新解释；
6. 可在真实台球语法上重新定义目标球价值。

## 风险

1. 容易被拿传统台球手感和规则严格比较；
2. 功能墙可能妨碍纯台球玩家；
3. 落袋导致数字球不断离桌，残局加工资源会减少；
4. Roguelite 徽章可能破坏竞技公平；
5. 单机“碰撞即收集”的原始惊艳感会被削弱；
6. 产品可能被定位成小众台球变体，而不是独立构筑游戏。

## 适合的美术

- 俱乐部、竞技、街头、机械台球；
- 六袋结构清楚；
- 球体保持可信材质；
- 功能墙像台边附件或桌面机关；
- UI 尊重台球信息层级，不覆盖球桌。

# 三、方案 B：纯碰撞构筑游戏

## 玩家第一认知

> 发射核心，撞击彩色数字体，利用反弹和机关加工组合。

它可以保留“桌面”和“球杆式蓄力”，但不再声称遵守台球：

- 不一定有袋口；
- 撞到即可激活或收集；
- 墙、传送门、移动机关和区域效果可以更自由；
- 母球可以是核心、弹珠、探针或能量体；
- 球桌可变成竞技盘、机械装置、炼金台或抽象物理场。

## 优势

1. 与现有核心 Demo 一致，迁移成本低；
2. 一杆多撞、抢球、功能墙加工更直接；
3. 不受台球犯规与落袋规则约束；
4. 章节机关和 Boss 桌设计空间大；
5. 徽章可以大胆改变物理规则；
6. 更容易形成独立品类身份，而不是台球变体。

## 风险

1. 会失去台球用户的自然目标与熟悉技巧；
2. “为什么撞一下就算收集”需要良好世界规则表达；
3. 没有落袋后，球桌清理和目标完成方式需要重做；
4. PvP 的球权、犯规和胜负不再天然；
5. 若包装过于抽象，会像机制玩具或网页小游戏；
6. 必须建立自己的操作词汇，市场教育成本更高。

## 适合的美术

- 机械竞技盘；
- 奥术碰撞仪；
- 玻璃数字核心；
- 弹珠机器；
- 微缩工坊或桌面装置；
- 不必使用绿色台呢、传统球袋和标准球杆。

# 四、不推荐的折中

## 1. 基础模式同时使用“撞到收集”和“落袋收集”

容易出现：

- 玩家不知道到底为何瞄准；
- 撞到已经得球，落袋价值不足；
- 落袋后球消失，与残局经营冲突；
- 教程和 UI 负担增加；
- 两套玩家直觉互相打架。

## 2. 外观像传统台球，但规则完全不遵守台球

这是最容易制造违和的版本。台球用户会自然期待：

- 落袋；
- 球权；
- 犯规；
- 走位；
- 球号规则。

如果实际只需碰撞收集，传统外观会不断承诺不存在的规则。

## 3. 把球换成玩偶，但保留精确圆形碰撞

外观判定不一致，数字颜色读取变差，还会引入角色能力预期。

# 五、推荐的比较实验

在 Godot 技术底座完成后，用同一张基础球桌制作两个 5～10 分钟切片。

## 切片 A：落袋满贯

- 六袋桌；
- 10 颗数字球；
- 落袋才收集；
- 合法进球续杆；
- 母球犯规；
- 复制墙、染色墙；
- 锁分 / 继续连杆；
- 一名简单 AI 或本地双人。

## 切片 B：碰撞满贯

- 无袋或袋口仅作清理；
- 8 颗数字球；
- 碰撞即激活收集；
- 五档力度；
- 复制墙、染色墙；
- 立即结算 / 保留球组；
- 单机目标分与本地共享桌对抗各一局。

## 同一批测试者比较

记录：

1. 10 秒内是否知道目标；
2. 是否主动再打一局；
3. 普通操作与漂亮操作差距；
4. 功能墙主动使用率；
5. 是否产生走位 / 做球 / 连锁规划；
6. 对规则的错误预期；
7. 单局时长与等待；
8. 更愿意购买哪一版；
9. 能否用一句话复述产品；
10. 台球经验对评价的影响。

---

# 六、最终结论

正式产品锁定为：

> **以圆球、球杆式蓄力、库边反弹为物理语言的碰撞构筑游戏。**

核心不变：

```text
碰撞收集
→ 功能墙加工
→ 五球组合
→ 结算或保留
→ 六球爆仓
```

不再制作落袋满贯对照切片。Godot 技术纵切直接复现并提升现有碰撞核心。

为了避免误导传统台球玩家：

- 美术可保留台球触感，但不照搬标准酒吧台球桌；
- 商店文案不宣传八球、斯诺克或真实台球模拟；
- 球袋只可作为清理、回收、奖励或章节机关；
- 可选加入走位、旋转和安全球技巧，但它们服务碰撞做球，而不是替换收集规则。

台球用户不是靠复制传统规则争取，而是靠熟悉的击球手感、反弹技巧、走位深度和物理可信度吸引。
